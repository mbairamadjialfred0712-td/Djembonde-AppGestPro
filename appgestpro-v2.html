FAQ

Questions fréquentes

Tout ce que vous voulez savoir avant de démarrer votre projet.

Combien de temps pour avoir mon application ?+
Pour l'App Boutique Starter, livraison en 5 jours ouvrés. Pour l'App PME Pro, 7 jours. Pour les apps sur mesure, le délai est défini lors de la consultation gratuite selon la complexité du projet.
Est-ce que l'app fonctionne sans connexion internet ?+
Oui. Nos applications sont conçues pour fonctionner en mode hors-ligne. Les données se synchronisent automatiquement dès que la connexion est rétablie. Idéal pour l'Afrique.
Sur quel type de téléphone ça marche ?+
Nos applications sont compatibles Android (depuis version 7) et iOS (iPhone). Elles fonctionnent aussi sur tablette. Une version web accessible depuis n'importe quel navigateur est disponible sur demande.
Comment se passe le paiement ?+
Un acompte de 50% est demandé au démarrage du projet. Le solde est payé à la livraison. On accepte Wave, Flooz, Mobile Money et virement bancaire.
Que se passe-t-il si j'ai un problème après livraison ?+
Toutes nos applications incluent 30 jours de support gratuit après livraison. Si un bug est détecté, on le corrige sans frais supplémentaires. Un suivi peut être prolongé sur abonnement mensuel.
Puis-je voir une démo avant de payer ?+
Absolument. Lors de la consultation gratuite, nous vous présentons des exemples d'applications déjà réalisées. Pour les projets sur mesure, une démo interactive est présentée avant la livraison finale.
